Thank you for installing NightShiftCtl __VERSION__!

Open NightShiftCtl from your Applications folder. It lives in the menu bar: look for the moon icon near the clock. There is no Dock icon.

On a MacBook with a notch, a crowded menu bar can hide the moon behind the notch. Quit a few menu bar apps, or hold Command and drag the moon to the right.

The nightshift command line tool is installed in /usr/local/bin. Run nightshift help to get started.

If NightShiftCtl is useful to you, please star it on GitHub and share it with a Mac admin friend. It really helps, and it keeps the updates coming.
